## What it is

A **DeepSeek Harness plugin (bundle)** that adds two native tools:

| Tool | What it does | Costs credits |
| --- | --- | --- |
| `seedance_generate` | Text-to-video: submit → poll → save the MP4 into the workspace | ✅ yes |
| `seedance_status` | Report sign-in state and remaining credits | ❌ no |

After installing, just ask in dsh: *"generate a video with seedance of ..."* — the agent produces the clip and puts the file in your workspace. **No need to open the Jimeng app, paste an API key, or run a side service.**

## Features

- **Seedance 2.5 / 2.0 family**: `seedance-2.5`, `seedance-2.0`, `seedance-2.0-fast`, `seedance-2.0-mini`
- **Duration**: 4–30s on 2.5, 4–15s on 2.0
- **Aspect ratios**: `21:9` `16:9` `4:3` `1:1` `3:4` `9:16`
- **Auto-save**: named by timestamp + task id into `jimeng-videos/`
- **Credit pre-check**: fails fast before spending anything
- **Session auto-discovery**: finds the desktop cookie jar by itself
- **Network retry**: transport failures retry twice with a clear message

## Install

Requirements: DeepSeek Harness 0.2.x, the Jimeng desktop app installed and signed in, credits available, Node.js ≥ 22.5 (DSH ships Node 24).

```bash
git clone https://github.com/MokoKing666/dsh-jimeng-seedance.git
cd dsh-jimeng-seedance
dsh plugin --profile desktop add .
```

If the tools do not appear afterwards, restart dsh once — host-side plugins resolve module paths at process start.

### `seedance_generate`

| Parameter | Type | Default | Notes |
| --- | --- | --- | --- |
| `prompt` | string | **required** | Chinese prompts work best |
| `model` | string | `seedance-2.5` | |
| `ratio` | string | `16:9` | |
| `duration` | integer | `5` | 4–30 (2.5), 4–15 (2.0) |
| `resolution` | string | `720p` | web session only exposes 720p |
| `download` | boolean | `true` | `false` returns the URL only |

## How it works

The desktop app is Electron and stores its session cookies in plaintext SQLite:

```
%APPDATA%\dreamina-desktop\Partitions\dreamina-web\Network\Cookies
```

The plugin reads `sessionid` from there with `node:sqlite`, signs requests the way the web client does
(`md5("9e2c|" + last 7 chars of uri + "|7|5.8.0|" + timestamp + "||11ac")`), then calls
`/mweb/v1/aigc_draft/generate` to submit and `/mweb/v1/get_history_by_ids` to poll.

| Parameter | `model_req_key` |
| --- | --- |
| `seedance-2.5` | `dreamina_seedance_45_pro` |
| `seedance-2.0` | `dreamina_seedance_40_pro` |
| `seedance-2.0-fast` | `dreamina_seedance_40` |
| `seedance-2.0-mini` | `dreamina_seedance_40_mini` |

## Configuration

```yaml
- id: jimeng-seedance
  name: '@local/dsh-jimeng-seedance'
  config:
    cookieDbPath: ''          # empty = auto-detect
    downloadDir: jimeng-videos
    pollIntervalMs: 5000
    pollTimeoutMs: 900000
```

## Limitations

- Text-to-video only; image-to-video is not wired up yet
- 720p only (the web session exposes nothing higher)
- Signing out of the desktop app breaks it until you sign in again
- One task at a time
- Depends on the desktop cookie storage format
